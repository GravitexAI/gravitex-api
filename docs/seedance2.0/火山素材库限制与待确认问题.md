# 火山素材库（BytePlus Asset Library）限制清单

> 本文整理自火山官方文档 + 实际测试，标注了已知限制和待向火山官方确认的问题。

---

## 一、已知限制（官方文档明确标注）

### 1. QPS / QPM 限制（每账号）

| API | 限制 |
|---|---|
| CreateAssetGroup | 10 QPS |
| ListAssetGroups | 10 QPS |
| DeleteAssetGroup | 5 QPS |
| CreateAsset | **300 QPM**（注意是每分钟） |
| GetAsset | 100 QPS |
| ListAssets | 10 QPS |
| DeleteAsset | 10 QPS |

> 注：我们网关是多用户共享同一个 AK/SK 账号，所以这些 QPS 限制是所有用户共享的，不是每用户独立的。

### 2. 素材图片要求

| 项目 | 限制 |
|---|---|
| 格式 | jpeg, png, webp, bmp, tiff, gif, heic, heif |
| 大小 | 最大 30MB |
| 分辨率 | 300px ~ 6000px（宽和高都在此范围内） |
| 宽高比 | 0.4 ~ 2.5 |

### 3. 素材组类型

- 目前只支持 `AIGC`（虚拟人像）类型
- 素材类型支持：`Image`（图片）、`Video`（视频）、`Audio`（音频）

### 4. 素材处理

- 创建素材后是**异步处理**，状态流转：`Processing` → `Active`（成功）/ `Failed`（失败）
- 没有明确的处理时间 SLA（官方未承诺多久处理完）
- 需要轮询 `GetAsset` 查状态

### 5. 视频生成中引用素材的限制（Seedance 2.0）

| 素材类型 | 限制 |
|---|---|
| 参考图片 | 1~9 张（Seedance 2.0 多模态参考） |
| 参考视频 | 最多 3 个，总时长 ≤ 15秒，总大小 ≤ 50MB |
| 参考音频 | 最多 3 个，总时长 ≤ 15秒，总大小 ≤ 15MB |
| 首帧图（image-to-video） | 1 张（首帧）或 2 张（首帧+尾帧） |

### 6. 素材引用格式

- 在视频生成请求中使用 `asset://<Asset_Id>` 格式引用素材
- Asset_Id 就是创建素材时返回的 ID

## 二、未知限制（官方文档未明确标注）

以下是文档中**没有找到**明确说明的限制，需要向火山官方确认：

### 待确认问题清单

| # | 问题 | 我们当前的处理 | 备注 |
|---|---|---|---|
| 1 | **一个账号最多能创建多少个素材组？** | 网关设了 5 个/用户/渠道 的防御性限制 | 文档没说上限，但资源是共享的，需要知道 |
| 2 | **一个素材组最多能放多少个素材？** | 目前没限制 | 不知道有没有上限 |
| 3 | **一个账号总共能有多少个素材？** | 目前没限制 | 不知道有没有存储配额 |
| 4 | **素材组名字最大长度？** | 目前没校验 | 需要知道是否有字符数限制 |
| 5 | **素材名字最大长度？** | 目前没校验 | 同上 |
| 6 | **素材的有效期？会过期吗？** | 假设永久有效 | 不确定是否有 TTL |
| 7 | **素材处理大概需要多久？** | 前端轮询刷新 | 没有 SLA，实际体感是？ |
| 8 | **一个视频生成请求中，能混合使用不同素材组的素材吗？** | 网关只校验同渠道，没限制同组 | 火山侧是否有此限制？ |
| 9 | **DeleteAssetGroup 是否会自动删除组内素材？** | 我们本地做了级联删除 | 火山侧行为是？ |
| 10 | **素材 URL 必须公网可访问吗？有域名白名单限制吗？** | 目前用 OSS 公网 URL | 能否用内网 URL？ |
| 11 | **除了 AIGC 类型，后续会支持其他 GroupType 吗？** | 只用 AIGC | 了解未来规划 |
| 12 | **QPS 限制是硬限制还是软限制？超了会怎样？** | 未做客户端限流 | 返回 429？还是直接报错？ |

## 三、我们网关的自定义限制

| 限制 | 值 | 说明 |
|---|---|---|
| 每用户每渠道素材组数量 | 5 个 | `MaxAssetGroupsPerUserPerChannel` 常量，可调整 |

> 这个限制是我们自己设的防御性限制，不是火山的限制。因为同一渠道的 AK/SK 是多用户共享的，防止某个用户占用过多资源。

7. 视频生成时能否混合引用不同素材组的素材？
8. 删除素材组时，组内的素材是否会被自动删除？
9. 素材 URL 是否必须公网可访问？有域名白名单吗？
10. QPS 超限后的行为是什么？返回什么错误码？
