# 工具调用计费使用指南

## 概述

工具调用计费系统（Tool Call Billing）为 OpenAI / Claude / Gemini 的内置工具调用（web_search、file_search、image_generation、google_search）提供独立定价能力。工具调用费用在 token 计费之外**额外叠加**，不影响现有的倍率或阶梯计费逻辑。

**核心特性：**
- 按工具类型和模型独立定价（$/1K 次调用）
- 支持通配符前缀匹配，实现模型级价格覆盖
- 管理后台可视化表格 + JSON 双模式编辑
- 自动从上游响应中统计工具调用次数
- 附加费已内含分组倍率，直接叠加到总额度

## 二、价格匹配算法

当需要查询某个工具在某个模型上的价格时，系统按以下优先级匹配：

```
1. 最长模型前缀匹配（精确度最高）
   例: web_search_preview:gpt-4o-mini* 匹配 gpt-4o-mini-2024-07-18

2. 工具默认价格
   例: web_search_preview 默认 $10.0/1K

3. 零值（无附加费）
   工具未配置任何价格时，不收取附加费
```

**前缀匹配规则：** 系统按前缀长度降序排列，第一个匹配的前缀胜出，确保最具体的规则优先。

**示例：**

模型 `gpt-4o-mini-2024-07-18` 的 `web_search_preview` 价格查找：

1. 检查前缀列表（按长度降序）：`gpt-4o-mini` → `gpt-4.1-mini` → `gpt-4o` → `gpt-4.1`
2. `gpt-4o-mini` 匹配 → 返回 $25.0/1K
3. 若都不匹配 → 返回默认 $10.0/1K

## 三、附加费计算公式

### 3.1 标准工具（web_search, file_search, google_search）

```
surcharge_quota = (price_per_1K / 1000) × call_count × groupRatio × QuotaPerUnit
```

各参数含义：
- `price_per_1K`：通过匹配算法获得的工具价格（$/1K 次调用）
- `call_count`：本次请求中该工具的实际调用次数
- `groupRatio`：用户分组倍率
- `QuotaPerUnit`：500,000（系统额度单位常量）

**示例：** 用户 groupRatio=1.0，使用 gpt-4o 模型触发 3 次 web_search_preview：
```
surcharge = (25.0 / 1000) × 3 × 1.0 × 500,000 = 37,500 额度
```

### 3.2 图片生成工具（image_generation）

```
surcharge_quota = per_call_price × groupRatio × QuotaPerUnit
```

注意：图片生成是按每次调用的固定价格，**不除以 1000**。

**示例：** high quality, 1024x1024 图片生成：
```
surcharge = 0.167 × 1.0 × 500,000 = 83,500 额度
```

### 3.3 总额度计算

工具附加费**已内含 groupRatio**，直接叠加到 token 计费结果：

**倍率模式（ratio）：**
```
总额度 = (输入额度 + 输出额度) × modelRatio × groupRatio + 工具附加费
```

**固定价格模式（price）：**
```
总额度 = modelPrice × QuotaPerUnit × groupRatio + 工具附加费
```

**阶梯计费模式（tiered_expr）：**
```
总额度 = Round(tieredResult.ActualQuotaBeforeGroup × groupRatio + 工具附加费)
```

## 四、工具调用次数追踪

不同提供商和 API 格式的追踪机制各不相同：

### 4.1 OpenAI Responses API（web_search_preview, file_search）

- **初始化：** 请求解析时，根据请求中的 tools 列表创建 `BuiltInTools` 追踪映射
- **非流式：** 响应返回后遍历 `responsesResponse.Tools`，匹配类型累加 `CallCount`
- **流式：** 监听 `response.output_item.done` 事件，`type == "web_search_call"` 时累加计数

### 4.2 Claude Web Search

- Claude 在响应 usage 中直接返回调用次数：`claudeResponse.Usage.ServerToolUse.WebSearchRequests`
- 流式和非流式均通过 Gin context key `claude_web_search_requests` 传递

### 4.3 OpenAI 图片生成（Responses API）

- 检测响应输出项中 `type == "image_generation_call"` 的条目
- 提取 quality 和 size 参数
- 通过 Gin context keys 传递：`image_generation_call`、`image_generation_call_quality`、`image_generation_call_size`

### 4.4 搜索预览模型回退

模型名以 `search-preview` 结尾时（如 `gpt-4o-search-preview`），若无 Responses API 追踪数据，自动按 **1 次 web search 调用** 计费。

## 五、管理后台配置

### 5.1 访问路径

**系统设置 → 分组与模型定价设置 → 工具价格设置**

### 5.2 可视化编辑模式

默认展示表格视图：

| 列 | 说明 |
|----|------|
| 工具标识符 | 文本输入，如 `web_search` 或 `web_search_preview:gpt-4o*` |
| 价格 ($/1K) | 数字输入，最小值 0，步进 0.5 |
| 操作 | 删除按钮 |

- **添加：** 点击"添加"按钮新增一行
- **恢复默认：** 恢复系统内置的默认价格表
- **保存：** 提交到后端 `PUT /api/option/`

### 5.3 JSON 编辑模式

切换到 JSON 模式可直接编辑原始配置：

```json
{
  "web_search": 10.0,
  "web_search_preview": 10.0,
  "web_search_preview:gpt-4o*": 25.0,
  "web_search_preview:gpt-4.1*": 25.0,
  "web_search_preview:gpt-4o-mini*": 25.0,
  "web_search_preview:gpt-4.1-mini*": 25.0,
  "file_search": 2.5,
  "google_search": 14.0
}
```

**格式说明：**
- 键 `"tool_name"`：该工具的默认价格
- 键 `"tool_name:model_prefix*"`：模型前缀覆盖价格
- `*` 尾缀为可视化标记，系统在解析时会去掉

JSON 模式提供实时语法校验，必须是非 null、非数组的 JSON 对象。

### 5.4 存储位置

| Option 表键 | 值类型 | 说明 |
|-------------|--------|------|
| `tool_price_setting.prices` | JSON 字符串 | 工具价格配置映射 |

### 5.5 优先级合并

保存后系统按以下优先级合并价格：

```
1. 数据库持久化配置（管理员设置，最高优先级）
2. 代码内置模型前缀覆盖（defaultToolPriceOverrides）
3. 代码内置默认价格（defaultToolPrices，最低优先级）
```

合并后原子性替换运行时索引，对在途请求无影响。

## 七、Claude vs OpenAI Web Search 差异对比

| 维度 | Claude Web Search | OpenAI Web Search |
|------|-------------------|-------------------|
| **计费键名** | `web_search` | `web_search_preview` |
| **调用次数来源** | 响应 usage 中 `ServerToolUse.WebSearchRequests` | 遍历响应 output items 计数 |
| **传递方式** | Gin context key `claude_web_search_requests` | `RelayInfo.ResponsesUsageInfo.BuiltInTools` |
| **价格查找** | `GetToolPrice("web_search")` — 无模型覆盖 | `GetToolPriceForModel("web_search_preview", model)` — 支持模型前缀覆盖 |
| **默认价格** | $10.0/1K | $10.0/1K（gpt-4o/4.1 系列为 $25.0/1K） |
| **请求转换** | OpenAI `WebSearchOptions` → Claude `web_search_20250305`，`max_uses` 映射：low=1, medium=5, high=10 | 原生 Responses API `web_search_preview` 类型 |

## 八、按调用计费模型说明

**重要：** 当模型使用按次调用计费（model_price 模式）时，工具调用不额外收取附加费。这是因为按次调用价格通常已经包含了工具使用成本。

管理后台顶部的提示信息也说明了这一点：
> "按次计费模型不额外收取工具费用"

## 九、常见问题

### Q: 如何为新模型添加工具价格覆盖？

在管理后台工具价格设置中，添加格式为 `工具名:模型前缀*` 的条目。例如，为 `gpt-5` 系列的 web_search_preview 设置 $30/1K：
```
web_search_preview:gpt-5* → 30.0
```

### Q: google_search 是否已生效？

`google_search` 已在价格表中定义（$14.0/1K），但 Gemini 的 grounding search 调用计数追踪尚未完全集成到主计费路径。该配置为未来扩展预留。

### Q: 工具附加费是否受模型倍率（modelRatio）影响？

**不受影响。** 工具附加费仅受分组倍率（groupRatio）影响，与 modelRatio 无关。计算公式中已包含 groupRatio。

### Q: 如何禁用某个工具的附加费？

将该工具的价格设置为 `0`。例如将 `web_search` 设置为 0 即可禁用 Claude web search 的附加费。

## 十、API 调用示例（curl）

以下示例假设系统地址为 `http://localhost:3000`，管理员令牌为 `sk-admin-xxx`，用户令牌为 `sk-user-xxx`。

### 10.1 管理端：配置工具价格

**设置完整的工具价格表：**

```bash
curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer sk-admin-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "tool_price_setting.prices",
    "value": "{\"web_search\": 10.0, \"web_search_preview\": 10.0, \"web_search_preview:gpt-4o*\": 25.0, \"web_search_preview:gpt-4.1*\": 25.0, \"web_search_preview:gpt-4o-mini*\": 25.0, \"web_search_preview:gpt-4.1-mini*\": 25.0, \"file_search\": 2.5, \"google_search\": 14.0}"
  }'
```

**为新模型添加价格覆盖（如 gpt-5 系列 web search $30/1K）：**

```bash
curl -X PUT http://localhost:3000/api/option/ \
  -H "Authorization: Bearer sk-admin-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "tool_price_setting.prices",
    "value": "{\"web_search\": 10.0, \"web_search_preview\": 10.0, \"web_search_preview:gpt-4o*\": 25.0, \"web_search_preview:gpt-5*\": 30.0, \"file_search\": 2.5, \"google_search\": 14.0}"
  }'
```

**禁用某个工具的附加费（设为 0）：**

```bash
# 禁用 Claude web search 附加费
curl -X PUT http://localhost:3000/api/option/ \

```

### 10.2 用户端：OpenAI Responses API — Web Search

**非流式调用：**

```bash
curl -X POST http://localhost:3000/v1/responses \
  -H "Authorization: Bearer sk-user-xxx" \
  -H "Content-Type: application/json" \

      }
    ]
  }'
```

```bash
curl -X POST http://localhost:3000/v1/responses \
  -H "Authorization: Bearer sk-user-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "input": "搜索今天的科技新闻",
    "stream": true,
    "tools": [
      {
        "type": "web_search_preview"
      }
    ]
  }'
```

> 计费说明：gpt-4o 模型匹配 `web_search_preview:gpt-4o*` → $25.0/1K 次调用。每次 web search 调用按 `25.0 / 1000 × groupRatio × 500000` 计算额外附加费。
