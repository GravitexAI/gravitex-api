### 2.3 `otherRatios` 私有化的调用点改造

官方把 `PriceData.OtherRatios` 从公开字段改成私有 `otherRatios` + 访问器。所有调用点改造：

| 原写法 | 改为 |
|---|---|
| `len(pd.OtherRatios) > 0` + `for range pd.OtherRatios` 乘倍率 | `pd.ApplyOtherRatiosToDecimal(value)` |
| `pd.OtherRatios["n"]` 读单值 | `pd.OtherRatios()["n"]` |
| `_, has := pd.OtherRatios["n"]` 判存在 | `pd.HasOtherRatio("n")` |
| `pd.OtherRatios = map[...]{...}` 整体赋值 | `pd.ReplaceOtherRatios(map[...]{...})` |
| `pd.OtherRatios[k] = v` 单键写入 | `pd.AddOtherRatio(k, v)` |

改动文件：`service/text_quota.go`、`relay/image_handler.go`、`relay/relay_task.go`、`relay/channel/task/ali/adaptor.go`、`relay/channel/task/vertex/adaptor.go`

注意：`model.TaskBillingContext.OtherRatios` 是另一个结构体的字段，**不受影响**，不要误改。

## 四、注意事项

### 4.1 `X-New-Api-Version` 响应头改名

main-alpha 的 commit `7f304157d` 把 `X-New-Api-Version` 响应头改成了 `X-Api-Version`。这个改动已在 main-alpha 分支历史中，本次合并按原样带入。项目 `AGENTS.md` 将 new-api 相关标识列为受保护信息，所以这一项**没有写入防丢清单**——如果将来官方更新把它改回 `X-New-Api-Version`，按项目政策应当接受官方的版本。

### 4.2 渠道类型号可能撞号

main-alpha 自己占用了 `ChannelTypeTencentTokenHub = 61` 和 `ChannelTypeSeedanceGateway = 62`。官方在待合并的 110 个 commit 里也新增了渠道类型（`08f88d25e` Tencent TokenHub、`398cdafec` New API 渠道、`2d23cdf29` Sub2API）。**下一阶段合并时必须核对号段是否冲突**，如冲突需给 main-alpha 的重新编号并写数据迁移。
