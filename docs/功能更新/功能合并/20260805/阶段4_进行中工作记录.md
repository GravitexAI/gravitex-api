## 三、relaykit 架构关键事实

- **relaykit 是独立 Go module**：`relaykit/go.mod`，module path `github.com/QuantumNous/new-api/relaykit`
- 主 module 用 `replace github.com/QuantumNous/new-api/relaykit => ./relaykit` 引用
- relaykit 只依赖 5 个第三方包：`uuid`、`lo`、`testify`、`gjson`、`sjson` —— **不能 import `gin`/`common`/`model`/`setting`**
- 官方的依赖替代方案：
  - `types/` 错误类型 → 复制进 `relaykit/types/`（`OpenAIError`/`ClaudeError`/`NewAPIError`/`ErrorCode` 等）
  - `common` 工具函数 → `relaykit/relayconvert/kitutil/`（json/log/mask/value）
  - `gin.Context` → `context.Context`
  - `*relaycommon.RelayInfo` → `convmeta.Meta` 接口
  - 全局 settings → `convmeta.Options` 快照

### types 包分家规则（重要）

| 类型 | 归属 |
|---|---|
| `OpenAIError` / `ClaudeError` / `NewAPIError` / `ErrorType` / `ErrorCode` / `FileSource` / `RelayFormat` / `EndpointType` / `ChannelError` / `RequestMeta` | `relaykit/types/` |
| **`PriceData`** / `RWMap` / `Set` | **主 module `types/`（不变）** |

官方在同时用两者的文件里，把主 module 的 types 起别名为 **`hosttypes`**。

`relaykit/relayconvert` 的 18 个子包：`dto` `reasonmap` `relayconvert{,/convmeta,/internal/{claude_messages,gemini_chat,jsonutil,media,oai_chat,oai_responses,shared/claude,shared/gemini},/kitutil,/reasoning,/testdata/golden/{request,response,stream}}` `types`
