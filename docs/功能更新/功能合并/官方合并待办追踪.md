## 六、本轮合并的技术决策记录

在合并到 `df01273b9` 时做的关键取舍，供后续参考：

| 文件 | 决策 | 原因 |
|---|---|---|
| `types/price_data.go` | 接受官方 `otherRatios` 私有化 + 访问器 API，保留 main-alpha 的 `VideoRatio` 字段 | 官方封装更安全（NaN/Inf 过滤）；调用点全部改用 `AddOtherRatio` / `ReplaceOtherRatios` / `OtherRatios()` / `HasOtherRatio` |
| `relay/channel/task/ali/adaptor.go` | **整体取 main-alpha 版** | main-alpha 支持 13 个 wan 模型（含 r2v）且有 `AdjustBillingOnSubmit/OnComplete` 计费引擎；官方只 5 个模型无计费。官方的 `normalizeWan27I2VInput` / `firstTaskImage` 等是同功能的另一套实现，混用会破坏计费 |
| `relay/channel/task/kling/adaptor.go` | **整体取 main-alpha 版** | 官方新增的 `FinalUnitDeduction` 计费依赖官方独有响应结构；main-alpha 有自己的 `AdjustBillingOnComplete` 计费路径 |
| `relay/channel/task/doubao/adaptor.go` | 取官方版（超集 + 指针类型） | 官方多 `Tools`/`SafetyIdentifier`/`Priority`，且 `Duration`/`Frames`/`Seed` 改指针符合 AGENTS.md「可选标量必须指针+omitempty」规范。赋值处已同步改为取地址 |
| `service/download.go` | **两者结合**：官方 SSRF 防护 client + main-alpha 浏览器请求头 | SSRF 是安全修复不能丢；浏览器 UA 是 Claude 媒体 URL 下载能成功的前提 |
| `model/log.go` | 保留 main-alpha 的 `gopool.Go` 异步 | 这是 QuotaDataStream 关闭时的兼容回退路径，同步会阻塞请求 |
| `controller/task_video.go` | 取官方的 `QuotaFromFloatChecked` 溢出保护 | 防止 quota 算成负数，是真实修复 |
| `service/quota.go` / `task_billing.go` / `text_quota.go` | main-alpha 的 `system_request_id` + 官方的 `attachQuotaSaturation` 都保留 | 互不冲突，都是日志字段增强 |
| `web/classic/src/i18n/locales/*.json` | 深度三方合并，ours 优先 + 吸收官方新键 | 每个文件保留 main-alpha 全部键（3600~4200 个），另加 5 个官方新键 |
| `relay/channel/task/ali/constants.go` | 取 main-alpha 模型列表 | 13 个 wan 模型 vs 官方 5 个，是超集 |
