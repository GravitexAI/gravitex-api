官方的前端改动路径是 `web/xxx`，我们的对应位置是 `web/default/xxx`。git 不会自动对应，所以：

**1) 先做后端合并，前端全部取 ours**
```bash
git merge <target> --no-ff --no-commit
# 前端一律取 ours（含 web/package.json、Dockerfile、main.go、router/web-router.go）
git checkout --ours web/ Dockerfile .gitignore
git add web/ Dockerfile .gitignore
# 然后逐个解决后端冲突
```

**2) 后端合完、build+test 通过后，再单独搬前端改动**
```bash
# 看官方这一段改了 web/ 下哪些文件
git diff --name-only <上次合并点> <target> -- web/

# 把官方 web/xxx 的 patch 映射到 web/default/xxx 再应用
git diff <上次合并点> <target> -- web/   | sed -E 's|(a\|b)/web/|\1/web/default/|g'   | git apply --3way --reject
# 有 .rej 就手动处理
```
