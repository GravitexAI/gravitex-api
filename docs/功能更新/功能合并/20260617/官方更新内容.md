# 官方 main 分支更新内容（2026-04-28 至 2026-06-17）

本次同步了官方 202 个提交。以下按功能模块整理。

---

## 一、前端大版本升级（双前端架构）

**这是本次更新最大的变化。** 官方推出了全新的"default"默认前端，原有前端改称"classic（经典版）"。两套前端共存，用户和管理员可在系统设置中切换。

- 新前端（default）：基于全新 UI 组件库重构，视觉风格现代化，支持主题预设（含 Anthropic 风格）、深色模式改进、响应式布局优化
- 新前端新增：模型排行榜页面、模型广场价格页面重设计、系统设置侧边栏重组
- 经典前端（classic）：保留原有功能，构建工具从 Vite 迁移到 Rsbuild，性能略有提升
- 新增"经典版 / 新版"切换入口，管理员可配置默认显示哪套前端

---

## 二、模型性能指标看板

- 系统自动采集每个模型的响应成功率、平均耗时等性能数据
- 管理后台 Dashboard 新增模型性能面板，可直观看到各模型的健康状态
- 支持按活跃分组过滤，只看你关心的模型组

---

## 三、安全审计日志

- 新增用户登录行为追踪：记录每次认证使用的方式（密码、OAuth、Passkey 等）
- 后台可查看用户的安全操作日志，包含本地化文案（中英文）
- 管理员可通过审计日志排查异常登录

---

## 四、渠道管理改进

- 渠道列表新增**分组过滤**：可按渠道所属分组筛选，方便大规模渠道管理
- 渠道列表支持**服务端排序**：可按多个字段排序（之前只能客户端排序，大数据量时有性能问题）
- 渠道被禁用后是否清空渠道粘性（Sticky Channel）现在可配置，不再强制清空
- 渠道测试对话框的交互体验改进：状态刷新更及时，不再闪烁

---

## 五、新支付渠道：Waffo Pancake

- 新增 Waffo Pancake 支付网关集成，支持订阅式付费
- 管理员可在后台绑定商品目录、配置订阅套餐
- 用户端支持通过 Waffo Pancake 购买余额或订阅

---

## 六、订阅功能扩展

- 订阅余额兑换可配置开关（之前固定开启）
- 付费功能开通前新增合规确认弹窗
- 管理员新增"订阅计划管理"接口，可直接修改用户的订阅状态

---

## 七、图片生成 API 增强

- 支持**流式图片生成**（Streaming Image）：图片生成过程中可实时返回部分结果，体验更流畅
- 支持图片编辑（Image Edit）的流式返回
- 图片质量参数（quality）处理逻辑修复：之前部分参数会被错误忽略

---

## 八、新模型支持

- Claude Opus 4.8（Anthropic 最新旗舰模型）
- Kimi k2.6（月之暗面）
- Codex 渠道更名为"ChatGPT Subscription (Codex)"，并简化了 OAuth 授权流程（原有的复杂 OAuth 流程下线，改为更简单的方式接入）

---

## 九、中继层（API 转发）优化

- 新增**中继空闲连接超时配置**：避免长时间空闲连接占用资源
- 新增**上游请求 ID 追踪**：系统会记录上游 API 返回的 Request ID，方便排查问题时对账
- 限制匿名用户请求体大小：防止未登录用户发送超大请求消耗服务器资源
- OpenAI o 系列模型适配范围收窄：避免误匹配非 o 系列模型

---

## 十、日志与用量记录改进

- 日志列表新增**已删除用户过滤**：可筛选出已注销用户的历史用量
- 后台用量日志表格 UI 改进：新增日志类型标识、头像展示、表格性能优化
- 用户 ID 现在显示在个人资料页面，方便用户自查

---

## 十一、其他小功能

- 支持 DeepChat 深度链接跳转
- 支持 `request_header` 类型的 API Key 来源（从请求头读取 Key）
- 管理员可对 API Key 发起分页搜索
- 渠道标签（Tag）模式支持从数据库分页加载，大量标签时性能更好
- WebhookM处理流程 bug 修复
- 多处前端显示 bug 修复（深色模式颜色、分页按钮文字、弹窗尺寸等）
