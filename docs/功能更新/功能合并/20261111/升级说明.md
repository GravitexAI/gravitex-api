## 二、OpenAI Chat 参数契约规则（代码内置，不涉及数据库）

规则写在 `relaykit/dto/openai_request.go`（`GetOpenAIChatCapabilities`）和 `relay/common/gpt6_chat_tools.go`（`gptChatToolRules`）里，随程序发布，**无需建表、执行 SQL 或改配置**。

### 2.1 哪些模型要整理参数

| 模型 | 判断方式 | `max_tokens` → `max_completion_tokens` | system → developer |
|---|---|---|---|
| `o1*` / `o3*` / `o4*` | 前缀匹配 | ✅ | ✅，但 `o1-mini`、`o1-preview` 除外 |
| `gpt-N*`，N ≥ 5 | 按世代号：gpt-5、gpt-5.6-sol、gpt-6-astra、gpt-7…… | ✅ | ✅ |
| 其他（gpt-4.1、gpt-4o、gpt-oss、gpt-image、claude 等） | — | 不动 | 不动 |

### 2.2 采样参数（temperature / top_p / logprobs / top_logprobs）

| 模型 | 规则 |
|---|---|
| o 系列 | 只剥 `temperature` |
| GPT-5+ 默认 | 全部剥掉 |
| 例外 1（官方）：`gpt-5.1` / `gpt-5.2` / `gpt-5.4`，含日期快照 | effort 为空或 none 时保留 |
| 例外 2（alpha）：GPT-5.6+ 家族（见 2.3） | effort 明确为 none 时保留（不支持 none 的型号除外） |
| 具名变体（`-pro`、`-codex`、`-chat-latest` 等） | 不继承例外 1 |

effort 取解析 `@effort:xxx` 修饰符与后缀之后的最终值。

### 2.3 GPT-5.6+ 家族（按顺序匹配，匹配原名或原名后接 `-xxx`）

| 前缀 | 支持 effort=none | effort=none 时保留采样参数 | Chat 接口的 function tools |
|---|---|---|---|
| `gpt-6-astra` | ❌（none 自动降为 low） | ❌ | 去掉 |
| `gpt-6.1-sol` | ❌（none 自动降为 low） | ❌ | 去掉 |
| `gpt-6.1`（含 `gpt-6.1-terra`） | ✅ | ✅ | 去掉 |
| `gpt-6-sol` | ✅ | ✅ | 仅 effort=none 时保留，因此强制改为 none |
| `gpt-6-luna` | ✅ | ✅ | 同上 |
| `gpt-5.6`（含 `-sol`、`-luna`、`-terra`、日期快照） | ✅ | ✅ | 同上 |

### 2.4 上新模型时要改哪里

- 新一代 GPT（比如 gpt-7）：不用改，按世代号自动套用
- 新模型需要「关闭推理时保留采样参数」或者有特殊的 tools 规则：在 `gptChatToolRules` 里加一行，具体型号要排在家族前缀前面
- 官方扩充例外 1 的型号列表：随官方合并自动进来
