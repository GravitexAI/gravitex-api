## Request parameters

<span id="rAfLg4ev"></span>
### Request body


---



**BytedToken** `string` `Required`

The unique credential identifier for this authentication, obtained from the response body of POST CreateVisualValidateSession.

**Caution** : The generated BytedToken will expire after a certain period. The validity period is 30 minutes. Please use it promptly (only one authentication is supported; repeated authentication is prohibited).


---



**ProjectName** `string`

The project name to which the resource belongs. The default value is default (case sensitive).

If the resource is not in the default project, you must enter the correct project name.

<span id="wANpcGgS"></span>
## Response parameters


---



**GroupId** `string`

The newly created portrait asset group for real\-person authentication.
