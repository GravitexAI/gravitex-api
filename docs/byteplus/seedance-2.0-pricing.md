## 三、每秒 token 消耗量（换算系数）

BytePlus 按 `tokens = 时长(秒) × 宽 × 高 × 帧率 / 1024` 计费（24fps）。折算成"每秒消耗的 token 数"后，各分辨率对应：

| 分辨率 | 每秒 tokens |
| --- | --- |
| 480P | 10,050 |
| 720P | 21,600 |
| 1080P | 48,600 |
| 4K | 194,400 |

> 该系数用官方 5 秒计费示例反推校验一致（720P/1080P/4K 完全吻合；480P 反推结果与其他分辨率一致）。

## 四、每秒价格 — 无视频输入（纯文本/图片生视频）

单位：USD / 秒，= 每秒 tokens × 单价 / 1,000,000

| 分辨率   | Seedance 2.0 | Seedance 2.0 Fast | Seedance 2.0 Mini |
| ----- | --------------------------- | --------------------------- | --------------------------- |
| 480P  | $0.0703/s | $0.0563/s | $0.0352/s |
| 720P  | $0.1512/s | $0.1210/s | $0.0756/s |
| 1080P | $0.3742/s | 不支持 | 不支持 |
| 4K    | $0.7776/s | 不支持 | 不支持 |

## 五、每秒价格 — 含视频输入（video-to-video / 带参考视频）

单位：USD / 秒，按"参考视频单价 × 每秒 tokens"简化换算：

| 分辨率   | Seedance 2.0 | Seedance 2.0 Fast | Seedance 2.0 Mini |
| ----- | ------------------------ | ------------------------ | ------------------- |
| 480P  | $0.0432/s | $0.0332/s | $0.0211/s |
| 720P  | $0.0929/s | $0.0713/s | $0.0454/s |
| 1080P | $0.2284/s | 不支持 | 不支持 |
| 4K    | $0.4666/s | 不支持 | 不支持 |

> 注意：这一栏是"参考视频单价直接套用输出时长的 token 数"算出的简化值。真实计费公式是 `tokens = (输入时长 + 输出时长) × 宽 × 高 × 帧率 / 1024`，也就是说参考视频本身的时长也会计入 token 数。如果参考视频比较长，实际账单会比表中数字更高；上表可视为"参考视频较短/可忽略"时的下限估算。

## 六、其他影响账单的因素

- 视频时长：4–15 秒可选，按秒线性计费。
- 宽高比：官方按 16:9 计算上表的宽高值，其他宽高比 token 数会略有差异（差异通常在 5% 以内）。
- Mini 的音频生成不额外计费。
