# 工作区交付规则

## 可复用流程

- 当前独立错误诊断开发以项目中的 `error_diagnosis.py` 为入口，只输入错误明细，不依赖 AI 或用量汇总。AI 建议由 `ai_analysis.py` 独立调用配置在 `.env` 中的兼容接口。
- 此软件项目需要保留必要源码、HTML 模板、测试、使用说明与 `.env`；“清理脚本”仅指临时或无用脚本，不删除可运行产品源码。`.env` 不纳入版本控制，不把密钥嵌入网页。
- 提供错误明细账单与用量汇总账单时，优先使用个人 skill `$billing-diagnostics`（`C:/Users/Fang088/.codex/skills/billing-diagnostics/SKILL.md`），复用其模板、生成脚本、统计口径与验证流程。项目仍只保留 HTML/Markdown 交付，skill 资源存放在个人 skills 目录。

## 输出

- 按报告所属的数据日期归档到 `output/YYYY-MM-DD/`，不使用任务生成日期或生成时间。例如 2026 年 9 月 14 日的数据归档到 `output/2026-09-14/`；文件名也注明数据日期。
- 每次只交付一个自包含 HTML 网页工具和一个精简 Markdown 分析报告。HTML 必须能离线使用，不依赖外部脚本、样式、JSON 或服务。
- 报告重点呈现数据对比、问题和优化方案；区分已确认事实、待核查原因与建议措施。
- 同一报告日期的后续修改更新对应日期目录中的 HTML 和 Markdown；新报告日期新建目录，保留其他日期的历史交付。
- 独立错误脚本跨日/周报按实际数据范围归档到 `output/YYYY-MM-DD_YYYY-MM-DD/`；日期未知时归档 `output/unknown-date/` 并明确标注，不使用生成日期替代。

## 清理

- 原始 Excel 等用户源文件保持原位，不修改、不删除。
- 临时脚本、抽取数据、截图、测试输出放到任务专属临时目录，完成验证后清除。
- 工作区不保留无用脚本、缓存、重复模板、PDF、ZIP、CSV、中间 JSON 或本地依赖目录。使用已有运行环境，不复制依赖到项目。
- 清理时先核对绝对路径和文件用途，只删除本任务临时资源或用户明确要求清理的内容；不得影响共享运行环境、其他项目或历史 HTML/MD 交付。

## 数据口径

- 资源分组不能当作实际渠道；缺失字段明确标注，不推测映射。
- 消费日志与错误记录不直接拼成成功率或失败率。
- Token 缓存读取占比不等于请求命中率；注意源表思考输出重复参与 Token 合计的口径。
- 缺少耗时、首字延迟或生成速度时，不以请求量代替性能指标。
